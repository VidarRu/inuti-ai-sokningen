# Inuti AI-sökningen

En svensk sida man scrollar sig igenom. Den följer en fråga genom en AI-söktjänst och visar var det kan gå fel. Systerprojekt till [Inuti AI-hjärnan](https://github.com/VidarRu/insidan-av-ai). Se `PROGRESS.md` för läget och `docs/PLAN.md` för planen.

```bash
npm install
npm run dev
```

Den tekniska spiken finns på `/spik.html`.
